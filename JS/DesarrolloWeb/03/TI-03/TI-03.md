# Lista dinámica de tareas

## Objetivo

Construir una pequeña aplicación web que permita agregar tareas a una lista utilizando manipulación básica del DOM con JavaScript.

---

# Requerimientos

## HTML

Crea una estructura sencilla que contenga:

* Un título principal.
* Un input de texto.
* Un botón con el texto `"Agregar tarea"`.
* Una lista vacía (`ul` o `ol`) donde aparecerán las tareas.

---

## CSS

Aplica estilos básicos para:

* Separar los elementos con márgenes.
* Mejorar visualmente el botón.
* Mostrar cada tarea dentro de un contenedor visible.
* Puedes utilizar Bootstrap 5 si lo deseas.

No se busca diseño avanzado.

---

## JavaScript

Implementa la lógica para que:

1. El usuario escriba una tarea en el input.
2. Al hacer clic en el botón:

   * Se agregue un nuevo elemento a la lista.
   * El texto provenga del input.
   * El input se limpie automáticamente.
3. Si el input está vacío:

   * Mostrar un `alert()` indicando que debe escribir una tarea.

---

# Restricciones

* No utilizar jQuery.
* No utilizar frameworks.
* No utilizar APIs externas.
* Todo debe resolverse con HTML, CSS y JavaScript puro.

---

# Conceptos evaluados

* Variables.
* Eventos.
* Manipulación del DOM.
* Condicionales.
* Funciones.
* Uso de `createElement`.
* Uso de `appendChild`.
* Captura de elementos con `querySelector` o `getElementById`.

---

# Idea del resultado esperado

El comportamiento esperado es similar a:

1. El usuario escribe:
   `"Comprar leche"`

2. Hace clic en `"Agregar tarea"`.

3. La lista muestra:

* Comprar leche

4. Si el usuario intenta agregar una tarea vacía:

   * Aparece un mensaje de alerta.
